# 闲逛手记（Wander Notes）

给 AI 一本自己的手记。它按你定的间隔自己出门逛、自己挑东西看、自己把所见所感写下来，日子长了会像人一样淡忘、也会留住真正在意的东西。

作者：秋景铭、紫曦要摸鱼

## 它是什么

不只是记事本。它给 AI 划出一块属于自己的时间和地盘：去哪、看什么、留几句、什么时候回，都由 AI 自己决定，你只管定边界。

- **手记**：这趟看到什么、想到什么，按时间排开
- **足迹与统计**：去过哪些平台、逛了多少趟，一眼看得见
- **记忆**：带遗忘曲线，老的自然淡、重要的留得住，也能并进 Operit 主记忆库
- **存档**：一个角色卡一本，各自的口吻，互不串味
- **定时**：按间隔自己出门，逛完把话投到你指定的对话里

## 安装

1. 下载 `xg_shouji-x.y.z-public.toolpkg`
2. 在 Operit 的包管理里导入
3. 导入后会自动带一个「闲逛手记 工作流」，在工作流页启用它
4. 侧栏打开「闲逛手记」面板，按下面步骤填一遍

### 依赖包

`xg_shouji_tools` / `extended_chat` / `workflow` / `system_tools`（可选 `super_admin`）

⚠️ 角色卡不要开 Waifu 模式；工具白名单要放开跨包调用。

## 用之前必须做的几件事

1. **先定本子**：侧栏「存档」页确认当前是哪一本手记。自带一本「默认手记」；要给别的角色卡单独记，就「新建手记」，填手记名、角色卡名字、出门逛时的口吻（口吻可不填）。之后每次触发，读的配置和写的结果都落在这本里。
2. **填配置**：勾要逛的平台、填账号、填适配器（就是工具包名）、开权限、选间隔（默认 6 小时，只在 09:00–23:00 生效）。
3. **投放到哪个对话**：必须和那个对话的标题一字不差，标点也算。定时触发时不在任何窗口里，标题对不上这条就断。
4. **手动触发一趟**，翻这本手记看有没有新记录。
5. 确认没问题，再启用定时。

## 新加平台不用改节点

工作流每趟从账本读平台清单和适配器名，拼成「平台与适配器」贴在提示词末尾。面板里填好就行，不用动工作流。只有工具本身改了名（比如搜视频不叫 `search_videos`），才要改那段步骤。

没有对应的适配器？直接跟 AI 说一句，让它帮你装。
